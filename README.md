# My-Latest-Front-End-Portfolio
A high-performance, responsive portfolio website built to showcase modern web development capabilities, clean UI/UX design, and robust full-stack architecture. This project serves as a central hub for my personal brand, featured projects, and technical skills.

🛠️ Tech Stack & Architecture
- Frontend Core: Built with HTML5, semantic JavaScript (ES6+), and CSS3 for a solid, accessible foundation.
- Styling & UI: Utilizes Tailwind CSS for a highly utility-first, FontAwesome for icons, and Dribbble, Canva, Figma for web design, responsive, and pixel-perfect design featuring smooth dark/light mode transitions and modern layouts.
- Build Tool & Bundler: Powered by Vite to ensure lightning-fast Hot Module Replacement (HMR) and optimized production builds.
- Backend & Server: Backed by Node.js and Local Storage to handle local and server-side logic, routing, and secure API integrations.

✨ Key Features
- Blazing Fast Performance: Optimized asset delivery and minimal bundle sizes thanks to Vite.
- Component-Driven UI: Clean, maintainable layout structures styled dynamically with Tailwind.
- Responsive & Adaptive: Fully optimized for seamless viewing across ultra-wide monitors, laptops, tablets, and mobile devices.
- Interactive UX: Smooth scrolling, dynamic project filtering, and interactive UI elements driven by native JavaScript.
- Backend Integration: A structured Node.js environment ready for handling contact form submissions, dynamic content fetching, or API endpoints.

📦 Installation & Setup
To get a local copy up and running, follow these simple steps:

Clone the repository: 
```bash
git clone https://github.com/yourusername/portfolio.git 
```
2. **Navigate to the project directory:**
   
   ```bash 
   cd portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

4. **Start the local development server:**
   ```bash
   npm run dev
   ```

5. Build for production:
   ```bash
   npm run build
   ```
